# 使用说明

## 环境
推荐 macOS + Python 3。安装依赖：

```bash
python3 -m pip install python-docx
```

## 运行独立插入工具
在包含 DOCX 文件的目录运行：

```bash
python3 /path/to/scripts/insert_3x4_before_bank_header_no_borders_mac.py
```

程序列出当前目录中的 DOCX 文件，输入编号选择。输出文件使用新文件名，原文件不覆盖。

## 运行后检查
1. 在 Word/WPS 中打开新输出文件。
2. 检查新增3行×4列区域是否无边框。
3. 检查原11列表头边框和交易数据是否保持。
4. 核对分页、列宽、图片位置。
5. 查看终端统计；若结构异常被跳过，不要强行重跑在已处理文件上，应改用原文件检查。

## 其他格式处理版本
项目历史中有多个版本的格式处理脚本。使用前应确认所需版本和功能，不要把不同版本的脚本随意合并。提交时仅保存源码与文档，不提交个人银行数据或测试 DOCX。
