# 银行表格左边界调整工具（13张表、3厘米版本）

**源码：** [adjust_bank_13_tables_3cm.py](../../scripts/adjust_bank_13_tables_3cm.py)

## 用途
处理特定的13张银行表格，执行脚本中定义的3 cm 边界调整。

## 重要限制
这是针对特定文档布局的专用工具，不是通用银行信息表对齐器。运行前必须确认目标文档结构和表格顺序与脚本假设一致；不要直接用于任意银行对账单。

## 运行
依赖及输入要求以源码开头和运行提示为准。先在副本上试运行：
```bash
python3 /path/to/scripts/adjust_bank_13_tables_3cm.py
```

## 验收
检查13张目标表格是否正确匹配、调整距离是否符合预期，以及其他表格、图片和列宽是否保持。原件应保留。
