# 银行表格行快速删除工具

**源码：** [delete_bank_rows_fast.py](../../scripts/delete_bank_rows_fast.py)

## 用途
执行脚本中定义的银行表格行删除任务。它是专用删除工具，使用前必须确认匹配条件与目标文件一致。

## 风险提示
删除操作可能移除内容。不要在唯一原件上操作；确认代码中的匹配规则、行范围和输出路径后再运行。若无法确认具体删除范围，先不要运行。

## 运行
```bash
python3 /path/to/scripts/delete_bank_rows_fast.py
```
依赖与输入选择方式以脚本提示为准。

## 验收
逐项检查删除前后的表格行、交易金额、页数和图片；确认仅删除预期行，且原文件未被覆盖。
