# 工具：表头前插入3行×4列无边框区域

**脚本：** [scripts/insert_3x4_before_bank_header_no_borders_mac.py](../../scripts/insert_3x4_before_bank_header_no_borders_mac.py)

## 适用场景

只在你希望给标准银行交易11列表格前增加一块空白区域时使用。它是独立工具，不是完整的银行对账单排版程序。

## 会做什么

- 扫描文档中的表格，尝试识别标准11列表头。
- 满足脚本的插入条件时，在目标表格前插入3行×4个逻辑单元格。
- 新增单元格设置为无边框。
- 从当前目录列出 DOCX 文件，用户输入编号选择。
- 输出到新文件：`原文件名_插入3行4列.docx`。
- 若输出文件已存在，停止而不覆盖。

## 不会做什么

- 不执行全文字体统一或字符间距调整。
- 不执行银行信息表左右边界对齐。
- 不重排标准11列的列宽。
- 不清理或删除重复标题、段落、金额汇总行。
- 不执行其他版本的格式处理规则。
- 不应被当作所有银行对账单的通用修复程序。

## 运行环境

需要 Python 3 和 `python-docx`：

```bash
python3 -m pip install python-docx
```

在包含待处理 DOCX 文件的目录运行：

```bash
python3 /path/to/word/scripts/insert_3x4_before_bank_header_no_borders_mac.py
```

输入文件编号后，程序会生成新的 DOCX。原文件应保持不变。

## 运行后检查

1. 在 Word 或 WPS 中打开输出文件。
2. 确认新增区域是否为3行×4列且无边框。
3. 确认原11列表头边框、交易内容、列宽和图片未受影响。
4. 检查分页及实际显示效果。
5. 如果程序跳过目标表格或识别数量不符，不要假定处理成功；保留原件并检查日志/终端结果。

## 限制

DOCX 表格可能含合并单元格、底层网格与逻辑列数不一致等结构。程序的识别条件可能无法覆盖所有文档。实际 Word/WPS 版面需要逐份验收。
