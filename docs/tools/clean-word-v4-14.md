这是项目历史中单独保存的 Word 清理/格式处理版本，保留其当时的实现以便复现和比较。

## 使用前注意
- 这是独立的历史脚本，不会调用其他版本，也不包含其他工具的全部功能。
- 不要仅根据版本号认定它比其他脚本更适合当前文档；先阅读源码中的说明和处理规则。
- 对真实银行对账单先复制一份测试，确认删除规则、表格列宽、分页、图片及交易内容。
- 不要与其他版本合并成一个脚本。

## 运行
依赖与选择文件方式以源码顶部说明和运行提示为准。通常从含 DOCX 的目录执行：
```bash
python3 /path/to/scripts/versions/clean_word_v4_14.py
```

## 输出与验收
按脚本提示检查输出文件名，确保原件未覆盖。运行后在 Word/WPS 检查被处理的段落、表格宽度、金额和图片位置。
