# Word 内容清理与格式统一 V4.16（不改列宽）

**源码：** [clean_word_v4_16_no_width.py](../../scripts/clean_word_v4_16_no_width.py)

## 用途
处理 Word/WPS 转换后的 DOCX 文本与格式，重点是保留所有表格宽度，规范文字及单元格格式。

## 适用场景
需要清理内容格式，但不希望脚本重新分配表格、网格或单元格宽度时使用。

## 不会做什么
- 不主动改变表格/网格/单元格宽度。
- 不翻译内容，也不应无差别删除英文交易数据。
- 不应代替专门的银行信息边界对齐或表头前插入工具。

## 环境与运行
需要 Python 3.12+ 与 python-docx。把脚本放在方便访问的位置，在含 DOCX 文件的目录运行：
```bash
python3 -m pip install python-docx
python3 /path/to/scripts/clean_word_v4_16_no_width.py
```
按提示输入文件编号。

## 输出与保护
脚本说明中约定原件不覆盖，输出新 DOCX。请核对实际输出名及终端日志。

## 验收
在 Word/WPS 检查字体、表格宽度、分页、图片位置及被清理的段落。脚本中的固定行距可能造成部分字形显示偏紧，需检查。
