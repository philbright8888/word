# Word 格式处理 V4.8（银行信息左边界版本）

**源码：** [word_table_format_mac_v4_8_bank_left_align.py](../../scripts/versions/word_table_format_mac_v4_8_bank_left_align.py)

## 用途
保存 V4.8 银行信息表左边界对齐的历史实现。

## 运行
```bash
python3 -m pip install python-docx
python3 /path/to/scripts/versions/word_table_format_mac_v4_8_bank_left_align.py
```

## 注意
该版本仅实现其当时的左边界规则，不等同于后续左右边界严格对齐版本。不要用它代替 V4.9 及之后的版本要求。

## 验收
核对目标表格是否匹配、左边界是否正确、列宽及合并结构是否保留。
