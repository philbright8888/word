# DOCX 表格单元格结构扫描工具

**源码：** [scan_docx_table_cells.py](../../scripts/scan_docx_table_cells.py)

## 用途
扫描 DOCX 表格的行、单元格、文本和结构信息，用于排查合并单元格、底层网格与逻辑列数不一致等问题。

## 适用场景
修改表格前需要了解结构时使用。扫描报告可能包含文档文本，请先确认输出目录和隐私。

## 不会做什么
扫描器不应修改源 DOCX，也不能保证根据扫描结果自动修复所有结构。

## 运行
```bash
python3 /path/to/scripts/scan_docx_table_cells.py
```
按脚本提示选择文件/输出位置。

## 隐私与验收
不要将含真实账号、交易金额或个人信息的扫描报告提交到公开仓库。检查报告中表格数、行数、单元格数和网格信息是否与目标文档一致。
