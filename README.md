# Word 银行对账单工具集

本仓库由多个**独立工具**组成。每个工具只处理自己的指定任务，**不代表所有工具都会执行同一套排版规则**。运行前请先阅读对应工具说明页，再决定是否使用。

## 工具目录

| 工具 | 适用任务 | 独立说明 |
|---|---|---|
| 表头前插入3行×4列无边框区域 | 仅需在标准11列表格前插入空白区域时使用 | [查看工具说明](docs/tools/insert-3x4-before-bank-header.md) |

> 目前仓库只登记已实际放入仓库的工具。其他聊天中讨论过的格式处理、汇总行、银行信息对齐、VBA 等工具，只有在对应源码正式导入后，才会添加各自独立的说明页；不会假设它们都已存在或把它们合并成一个通用程序。

## 仓库结构

- `scripts/`：独立 Python 工具源码
- `docs/tools/`：一项工具一页，说明用途、适用范围、不会做什么、运行方法和输出文件
- `docs/PROJECT_SPEC.md`：项目级总规则与隐私要求
- `docs/USAGE.md`：通用运行及验收注意事项

## 通用安全原则

- 原文件不覆盖、不删除；输出新文件。
- 不提交真实银行对账单、账号、交易金额、测试 DOCX 或包含交易数据的扫描报告。
- 复杂合并单元格、分页或边框无法可靠判断时，优先跳过并记录，不应猜测性修改。
- 模拟测试不能替代在 Microsoft Word/WPS 中检查真实文档。
